# Spacebuilding Game

A space empire builder where you command colonies, fleets, and research — alongside **Astra**, an AI companion who plays with you and runs your empire while you're away.

## What makes this different

Most idle empire games use scripted bots. Spacebuilding gives you a **true AI co-ruler**:

- **Play together** — chat with Astra, ask for strategy, and let her execute builds, research, and exploration
- **Go offline** — set companion mode to `co_ruler` or `autonomous`; when you return, Astra reports what she did
- **Persistent empire** — colonies, resources, threats, and chat history are saved between sessions

## Quick start

```bash
npm install
npm run build --workspace=shared
npm run dev --workspace=server
# in another terminal
npm run dev --workspace=client
```

Open http://localhost:5173 (client) — API runs on http://localhost:3001.

### Enable the LLM companion

Create `server/.env`:

```env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
```

Without an API key, Astra uses a smart rule-based fallback that still chats and takes actions.

## Companion modes

| Mode | Behavior |
|------|----------|
| `advisory` | Talks only — no automatic actions |
| `co_ruler` | Acts once per cycle alongside you |
| `autonomous` | Aggressively manages the empire each cycle |

Set imperial **priority** (`expand`, `economy`, `research`, `defense`, `balanced`) to steer offline and co-ruler behavior.

## Project structure

```
shared/   Game engine, types, tick simulation, offline progress
server/   REST API, persistence, OpenAI companion integration
client/   React UI — colonies, fleet, research, companion chat
```

## API highlights

- `POST /api/empires` — create a new empire
- `POST /api/empires/:id/resume` — load save + simulate offline time
- `POST /api/empires/:id/tick` — advance game cycles
- `POST /api/empires/:id/chat` — talk to Astra (optionally executes actions)
- `PATCH /api/empires/:id/companion` — change mode, priority, automation flags
